# Data for Data Viz contains

### iButton data

- Contains data for 
  - 2024
  - 2025
  - 2026
- Temperature and humidity

### Intelligent nestbox data

- Contains data for
  - 2025
  - ... eventually 2026 
- Temperature, humidity, light intensity and noise level

### Nestbox data

- Contains nest information
  - Dates for nest building and breeding 
  - Number of eggs
  - Number of chicks
  - Orientation of nestbox
  - Height of nestbox

### Unsorted or duplicated data

- Contains
  - iButton data for 2024 with old nest ids
